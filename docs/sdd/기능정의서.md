## 0. 이 문서의 사용 규칙 (읽는 사람 필독)

이 문서는 **IA를 기반으로 각 화면에 반드시 들어가야 하는 기능 요구사항**을 정의한다.
**디자이너는 여기 정의된 기능·제약·디자인 의도의 범위 안에서만** 화면을 디자인하고,
**프론트엔드 개발자는 같은 표를 기준으로** 화면을 구현한다. → **하나의 문서, 두 직군 공용.**

**작성 규칙 (기능내역 열에 반드시 포함):**
1. **위치·형태**: "ㅇㅇ 기능은 ㅇㅇ 화면 ㅇㅇ 위치에 ㅇㅇ처럼 들어간다."
2. **정량 제약**: 최대/최소 개수, 자릿수, 기간, 시간(초), 금액 단위 등 숫자로.
3. **디자인 의도**: 토스트 노출 시간, 고정 영역(bg fixed), 포커스·키보드 타입, 넘침 처리(캐러셀/스크롤), input 타입, 비활성 조건 등.
4. **데이터/연동**: 서버 호출이 있으면 API·필드·에러 코드까지.

**요구사항 ID 체계:**
- `CP_R_*` 체험자(Reviewer) · `CP_O_*` 사장님(Owner) · `CP_AD_*` 운영팀(Admin) · `CP_C_*` 공통(Common)
- 요구사항(화면/기능영역) → 요구사항기능(개별 기능). 예: `CP_R_REQ3` 매장 상세 → `CP_R_REQ3_4` 채널 선택 칩.

**개발가능여부 표기:** ✅ 구현 완료 · 🔷 구현됨(정책 확정) · ⏳ 로드맵(미구현·설계만). 본 VER.1은 PG 외 전부 ✅/🔷.

**공통 UI 상수 (전 화면 적용):**
- 모바일 뷰포트 폭 **480px**, 하단 BottomNav 높이 `--bottom-nav-h: 72px`.
- 브랜드 컬러 Action Blue `#0066cc`, 다크 tile `#1d1d1f`, parchment `#f5f5f7`, hairline `#d2d2d7`.
- 등급 배지색 S/A/B/C/N. 금액 표기 `₩` + `toLocaleString()` (천단위 콤마), 100원 단위 반올림.
- 토스트/에러 문구는 **아래 표의 따옴표 문자열이 서버 응답·UI 카피 원문**이다 (임의 변경 금지).
